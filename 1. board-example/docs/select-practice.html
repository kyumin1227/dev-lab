기대 결과
username post_count
seed 데이터에선 모두 5개씩이라 평균(5)과 같아 0행 / ">" 대신 ">=" 로 바꾸면 전체 20행
정답 
SELECT username, post_count
FROM (
  SELECT   users.username,
           COUNT(posts.id) AS post_count
  FROM     users
  LEFT JOIN posts ON posts.user_id = users.id
  GROUP BY users.id
) AS stats
WHERE post_count > (
  SELECT AVG(cnt)
  FROM (
    SELECT   COUNT(id) AS cnt
    FROM     posts
    GROUP BY user_id
  )
)
ORDER BY post_count DESC;
풀이
FROM절 서브쿼리유저별 게시글 수를 먼저 구한 뒤(인라인 뷰 stats), 그 결과를 다시 WHERE로 필터링합니다. GROUP BY 결과를 WHERE로 바로 필터할 수 없어 이 패턴을 씁니다.

유저 활동 종합 랭킹
각 유저의 게시글 수 × 2 + 댓글 수를 활동 점수로 계산해 상위 5명을 조회하세요.
FROM절 서브쿼리산술 연산
기대 결과 (일부)
username post_count comment_count score
alice 5 10 20
… 상위 5명 (동점이면 알파벳 순)
정답 
SELECT
  u.username,
  COUNT(DISTINCT p.id)                       AS post_count,
  COUNT(DISTINCT c.id)                       AS comment_count,
  COUNT(DISTINCT p.id) * 2
    + COUNT(DISTINCT c.id)                    AS score
FROM      users    u
LEFT JOIN posts    p ON p.user_id = u.id
LEFT JOIN comments c ON c.user_id = u.id
GROUP BY u.id
ORDER BY score DESC, u.username ASC
LIMIT    5;
풀이
테이블 별칭(u, p, c)긴 테이블명을 짧은 별칭으로 줄여 가독성을 높입니다.
산술 연산SELECT절에서 집계 함수 결과에 바로 * 2 + 같은 연산을 적용할 수 있습니다.
다중 ORDER BY점수가 같으면 username 알파벳 순으로 정렬합니다.

최종 보스 — 인기 게시글 종합 분석
2024년 3월 이후 작성된 게시글 중, 댓글이 2개 이상인 게시글의 title, 작성자, 댓글 수를 댓글 많은 순 상위 5개로 조회하세요.
JOIN × 2WHEREGROUP BYHAVINGORDER BYLIMIT
기대 결과 (일부)
title author comment_count
GROUP BY 완전 이해 frank 2
… 최대 5행 (3월 이후 + 댓글 2개 이상)
정답 
SELECT   posts.title,
         users.username         AS author,
         COUNT(comments.id)     AS comment_count
FROM     posts
JOIN     users    ON posts.user_id  = users.id
LEFT JOIN comments ON comments.post_id = posts.id
WHERE    posts.created_at >= '2024-03-01'
GROUP BY posts.id
HAVING   COUNT(comments.id) >= 2
ORDER BY comment_count DESC
LIMIT    5;
풀이 — 실행 순서로 이해하기
① FROM+JOINposts, users, comments 세 테이블을 연결합니다.
② WHERE3월 이후 게시글만 남깁니다. (행 단위 필터)
③ GROUP BY게시글 id 기준으로 그룹화해 댓글 수를 집계합니다.
④ HAVING집계 결과 중 댓글 2개 이상인 그룹만 남깁니다.
⑤ ORDER BY댓글 많은 순으로 정렬합니다.
⑥ LIMIT상위 5개만 반환합니다.
