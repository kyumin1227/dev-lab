22
平均より多く投稿したユーザー
全ユーザーの平均投稿数より 多く投稿したユーザー の username と投稿数を取得してください。
FROM句サブクエリAVG
期待される結果
username post_count
seed データでは全員 5 件で平均（5）と同じため 0 行 / `>` を `>=` に変えると全20行
解答 
SELECT username, post_count
FROM (
  SELECT   users.username,
           COUNT(posts.id) AS post_count
  FROM     users
  LEFT JOIN posts ON posts.user_id = users.id
  GROUP BY users.id
) AS stats
WHERE post_count > (
  SELECT AVG(cnt)
  FROM (
    SELECT   COUNT(id) AS cnt
    FROM     posts
    GROUP BY user_id
  )
)
ORDER BY post_count DESC;
解説
FROM句サブクエリ先にユーザーごとの投稿数を求め（インラインビュー `stats`）、その結果をさらに WHERE で絞り込みます。 GROUP BY の結果は直接 WHERE で絞れないため、この形を使います。

ユーザー活動の総合ランキング
各ユーザーの 投稿数 × 2 + コメント数 を活動スコアとして計算し、上位5人を取得してください。
FROM句サブクエリ算術演算
期待される結果（一部）
username post_count comment_count score
alice 5 10 20
… 上位5人（同点ならアルファベット順）
解答 
SELECT
  u.username,
  COUNT(DISTINCT p.id)                       AS post_count,
  COUNT(DISTINCT c.id)                       AS comment_count,
  COUNT(DISTINCT p.id) * 2
    + COUNT(DISTINCT c.id)                    AS score
FROM      users    u
LEFT JOIN posts    p ON p.user_id = u.id
LEFT JOIN comments c ON c.user_id = u.id
GROUP BY u.id
ORDER BY score DESC, u.username ASC
LIMIT    5;
解説
テーブル別名（u, p, c）長いテーブル名を短い別名にして、読みやすさを高めています。
算術演算SELECT 句では、集計関数の結果にそのまま * 2 + ... のような演算を適用できます。
複数条件の ORDER BYスコアが同じ場合は username をアルファベット順で並べます。

最終ボス — 人気投稿の総合分析
2024年3月以降に作成された投稿のうち、コメントが2件以上ある投稿の title・投稿者・コメント数 を コメント数の多い順で上位5件取得してください。
JOIN × 2WHEREGROUP BYHAVINGORDER BYLIMIT
期待される結果（一部）
title author comment_count
GROUP BY を完全理解 frank 2
… 最大5行（3月以降 + コメント2件以上）
解答 
SELECT   posts.title,
         users.username         AS author,
         COUNT(comments.id)     AS comment_count
FROM     posts
JOIN     users    ON posts.user_id  = users.id
LEFT JOIN comments ON comments.post_id = posts.id
WHERE    posts.created_at >= '2024-03-01'
GROUP BY posts.id
HAVING   COUNT(comments.id) >= 2
ORDER BY comment_count DESC
LIMIT    5;
解説 — 実行順で理解する
① FROM+JOINposts・users・comments の3テーブルを結合します。
② WHERE3月以降の投稿だけを残します。（行単位のフィルタ）
③ GROUP BY投稿 id ごとにグループ化してコメント数を集計します。
④ HAVING集計結果のうち、コメントが2件以上あるグループだけを残します。
⑤ ORDER BYコメント数が多い順に並べます。
⑥ LIMIT上位5件だけ返します。
